BOSQUE ENCANTADO — FAMILIA PILOTO: BRUJAS Y BRUJOS

Esta versión conserva la página principal y añade un primer tratamiento visual más atmosférico al laboratorio independiente.

Incluye:
- La Herbolaria Errante como referencia visual pictórica principal.
- Referencias visuales para Brujo de Corteza y Alquimista del Bosque.
- Interfaz de laboratorio con modos coherente/libre y botones existentes.
- Ficha PNG y controles del prototipo original.

NOTA HONESTA SOBRE EL ESTADO:
Esta es una iteración piloto de dirección artística, no la biblioteca final de ilustraciones por capas. Las imágenes de referencia no son piezas modulares transparentes; las opciones de personalización del prototipo aún no se componen como capas pictóricas independientes. El siguiente paso artístico es producir ilustraciones completas por personaje y después las piezas compatibles con cada anatomía.

Para probar: descomprimir el ZIP completo y abrir index.html mediante servidor local o publicarlo completo en GitHub Pages. No subir solo laboratorio.html: necesita la carpeta assets.
